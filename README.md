# Small Hours

A 2–3 minute ASCII-rendered narrative browser game. Episode 1: Milo, a kitten lost in the dark.

**Play:** https://p4panash.github.io/small-hours/

## Develop

```sh
nvm use      # Node 24 (see .nvmrc)
npm install
npm run dev
```

Controls: WASD / arrows (or drag on touch), Shift to crouch. The top-right pill opens the debug panel.

Design and planning docs live in [`docs/`](docs/00-README.md).
